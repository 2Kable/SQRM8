# sqrm8: the SQRM8 display board (KiCad 10, script-generated)

What the board is: `../BOARD.md`.
Nothing here is opened or edited in the KiCad GUI: the scripts are the sources, the KiCad files are regenerated.

The generator tools (schgen/pcbgen/router/DRC wrappers, `board.sh`) are a private toolchain, used **in place and
read-only**; the committed KiCad files open in KiCad 10 without it:
- `KICAD_TOOLS` points at the tools directory (default: a sibling checkout, see `build_sch.py`);
- `PYTHONDONTWRITEBYTECODE=1` always, so importing `schgen`/`pcbgen` leaves no `__pycache__` in the excalibur repo;
- kicad-cli is the Flatpak one and only writes under `$HOME`: outputs go to the repo or `~/.cache/kicad-tools/sqrm8/`.

## Regenerate

```bash
export KICAD_TOOLS=<tools dir> PYTHONDONTWRITEBYTECODE=1
B=$(pwd)/hardware/pcb

# schematic: build_sch.py -> sqrm8.kicad_sch / sqrm8.kicad_sym / sym-lib-table, ERC (fails on any error or warning), netlist sqrm8.net
cd "$KICAD_TOOLS/../.." && tools/kicad/board.sh "$B" sch

# PDF of the sheet and a PNG preview (outside the repo)
"$KICAD_TOOLS/kc" sch export pdf -o ~/.cache/kicad-tools/sqrm8/sqrm8.pdf "$B/sqrm8.kicad_sch"
pdftoppm -r 80 -f 1 -l 1 -singlefile -png ~/.cache/kicad-tools/sqrm8/sqrm8.pdf ~/.cache/kicad-tools/sqrm8/sqrm8_sch

# board: build_pcb.py placement + zones (reuses routes.json), then the routes from routes_manual.py + the router
cd "$KICAD_TOOLS/../.." && tools/kicad/board.sh "$B" pcb
cd "$KICAD_TOOLS/../.." && tools/kicad/board.sh "$B" route --reset   # --reset reproduces the committed board; a cached re-route adds one more GND stitching via
cd "$KICAD_TOOLS/../.." && tools/kicad/board.sh "$B" check     # DRC + silk + USB pair + mech_check.py, exit 1 on any issue
cd "$KICAD_TOOLS/../.." && tools/kicad/board.sh "$B" render    # ~/.cache/kicad-tools/sqrm8/render/
```

`build_sch.py` prints `{'symbols', 'lib_symbols', 'single_use_labels'}` and exits non-zero if a net label is used only
once (a typo). ERC needs `sqrm8.pretty/` (footprint links are checked: without the library every symbol warns).
Order after a change: `sch` -> `route` (or `pcb` when only placement or silk changed) -> `check` -> `render`.
Revision P3 passes `check` with 0 violations, 0 unconnected, 0 parity. The fab set (`fab`) and its rotation table are
kept out of the repo (`work/`, gitignored).
P3 = P2 renamed sqrm8 and relabelled; the P3 design changes (rotate C4 away from the V-cut, draw the J1 pegs as plated
Ø0.80) are still to do.

## Files

| File | Role |
|---|---|
| `build_sch.py` | the circuit: stock symbols + two drawn here (AP3032KTR-G1, the 40-pin panel FPC with the ER-TFT040-3 pin names) |
| `sqrm8.kicad_sch`, `sqrm8.kicad_sym`, `sym-lib-table`, `sqrm8.net` | generated by `board.sh ... sch` |
| `build_lib.py`, `sqrm8.pretty/` | the footprints (stock copies + drawn ones) |
| `sqrm8.kicad_pro` | design rules (: clearance/track 0.15, via 0.45/0.3, copper-edge 1.0: the V-cut margin, it also keeps the pours 1 mm in) |
| `template.kicad_pcb` | board header only: 4 layers, 1.6 mm (JLC04161H-3313: 0.0994 prepreg, 1.265 core, 1 oz outer / 0.5 oz inner), black mask, ENIG. `aux_axis_origin` (fab origin = the board's lower-left corner) is still `0 0`: set it with the outline |
| `fp-lib-table` | `sqrm8` -> `${KIPRJMOD}/sqrm8.pretty` |
| `board.env` | `RENDER_ZOOM`, `MECH_CHECK` for `board.sh` |
| `build_pcb.py` | placement (`P`), board outline, zones (In1 GND, In2 +3V3 with a VBUS island, F/B GND pours), silk, antenna keep-out |
| `routes_manual.py` | every track and via, generated from lane tables (the J2 bus, B1-B5 under the module, USB pair, power) |
| `route_board.py`, `routes.json`, `dump.json` | the router driver (only adds GND stitching vias on P2), its saved routes, the board geometry it reads |
| `sqrm8.kicad_pcb` | generated by `board.sh ... route` |
| `mech_check.py` | courtyard overlap / board-edge checker on `build_pcb.P` |
| `panel_view.py` | the board drawn on the back of the panel (`panel_view.png`) and the stack section (`panel_section.png`), stdlib + PIL, from `sqrm8.kicad_pcb` |

## Schematic conventions

- One flat A3 sheet; every pin gets a stub and a global label or power symbol (no wires between symbols).
- Nets in capitals as in `BOARD.md`; the 3.3 V rail is `+3V3` (KiCad power symbol), the 5 V input `VBUS`.
- Footprints are `sqrm8:<name>`; every BOM part carries its LCSC code (`LCSC` field) and, for ICs/connectors, `MPN`.
- Pad names the symbols expect: USB-C shell `SH` (stock symbol), panel FPC anchor pads `S1`.
